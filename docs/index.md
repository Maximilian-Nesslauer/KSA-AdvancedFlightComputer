# Advanced Flight Computer

Maneuver planning, burn execution and closed-loop guidance for [Kitten Space Agency](https://ahwoo.com/app/100000/kitten-space-agency).
AFC adds one console for every feature: orbit quick-tools, flyby targeting, multi-pass burns, RCS-only burns and automatic staging.
Its powered guidance flies an ascent to orbit, a launch to a moon, a booster boostback and a pinpoint powered landing.
